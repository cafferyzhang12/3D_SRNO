## 2. 任务是什么，数据实际是什么

### 2.1 配对、各向异性的 3D 超分

任务为 **XY ×4、Z ×1**。输入是数据集已经提供的原生 LR，不是训练时把 HR 临时缩小出来的合成 LR。每张 LR 为 128×128，配对 HR 为 512×512；病例是按顺序排列的多张 XY 切片。

当前网络采用 2.5D 组织：在 XY 上做卷积、窗口注意力和上下采样，通过跨 Z 注意力利用相邻切片；不把 Z 方向放大四倍。新版本训练使用 **7×64×64 LR → 7×256×256 HR**，旧模型和论文对照使用 **5×32×32 LR → 5×128×128 HR**。张量统一为 `B×C×Z×Y×X`，灰度通道 `C=1`。

扩大到 64×64 LR 后，每个样本的 XY 面积是旧块的 4 倍，深度从 5 增至 7。它扩大了观测上下文，但不是每一步都直接训练完整 512×512 病例。

### 2.2 实际数据数量与使用边界

| 集合 | 病例数 | 配对切片数 | 实际用途 |
|---|---:|---:|---|
| TRAIN | 3,919 | 292,657 | 主模型训练、Haar 白化、图册银行、PCA、病例级交叉拟合、路由蒸馏 |
| VAL | 10 | 595 | 每轮完整病例验证、选模、超参数比较、插值诊断 |
| 历史固定 TEST | 84 | 14,991 | 独立论文基线冻结权重后的终评；v2 开发不使用 |

VAL 共 **155,975,680** 个 HR 体素；历史 TEST 的完整终评为 **3,929,800,704** 个 HR 体素。切片数按配对计，一对包含一个 LQ PNG 和一个 HQ PNG，不能把文件总数当作切片对数。

本次从 v2 的 `trainval_inventory.json.gz` 重新汇总确认：TRAIN 全部 3,919 例及 VAL 全部 10 例均为 **8 bit、LR shape=[128,128]、normalization_scale=255、offset=0**。读取公式为：

```text
intensity = (PNG_pixel - 0) / 255
```

这不是逐图 min-max，也不是逐病例 z-score。程序支持 16 bit 并不代表当前实际输入为 16 bit；当前模型处理的是已量化的 PNG 灰度，不应把归一化值直接解释为原始扫描仪的定量 MR 信号。

数据组织示意如下，本文不公开病例 ID 或逐病例路径清单：

```text
$HOME/data/MRI_SR/
  train/LQ/X4_png/<case>/<slice>.png
  train/HQ_png/<case>/<slice>.png
  val_small/LQ/X4_png/<case>/<slice>.png
  val_small/HQ_png/<case>/<slice>.png
  test/...                        # 历史固定终评来源
```

索引记录 `stems/indices/lq/hq/lr_shape/bits/normalization_scale/normalization_offset/channel_policy/scale/fingerprint`。按切片标号配对并保持 Z 顺序；缺片和连续段由数据模块处理，不能把不连续切片当作正常相邻层。`identical_rgb_to_gray` 允许真正灰度或三个通道完全相同的 RGB；它不等于任意彩色图像的随意灰度化。

历史 TEST 是既有固定抽样名单（84 例），不是本次重新随机拆分。本文只读取该流程已经生成的终评汇总，不据此选择 v2 超参数或权重。VAL 与 TEST 分布、病例数和切片数不同，不能拿 TEST SSIM 更高来证明该模型在 VAL 上优于另一个模型。

### 2.3 “每轮 262,144”与“3,919 例”的区别

每轮 **262,144 个随机配对 patch** 是训练抽样预算，既不表示新增了 262,144 个病例，也不表示全部 292,657 张切片每轮恰好访问一次。数据集按病例及随机空间/Z 位置抽取 patch，种子与 epoch 决定可复现的抽样过程。

新版本图册准备另有独立预算：每例 **1 个 patch、64 个 HF 邻域位置**。3,919 例对应约 **250,816 个 135 维纹理样本**。白化统计来自这些 TRAIN patch 的全部 Haar 位置；PCA/图册来自所抽取的纹理行。这是覆盖所有训练病例的有限采样估计，不能写成在所有训练切片或所有像素上穷尽拟合。

## 4. 从旧模型到新模型的具体变化

### 4.1 旧版本的局限及实测诊断

旧模型以双线性 XY 上采样为基底，在 5×32×32 LR 对应的 16 通道 Haar 残差上预测端点。多尺度 CNN 的 XY 网格为 32→16→8；没有当前的全 HR 精修头。旧正式配置 `sigma_0=sigma_bridge=0`，四步确定性迭代不能称为已经启用随机扩散。

旧微调每卡 batch=544、四卡全局 2,176，每轮仅 121 次更新，8 轮共 968 次，学习率 2e-5。SSIM 只覆盖部分样本，旧几何也没有推理在线修正。

已有真实 TRAIN 探针（2 个 patch、512 个图册位置）给出：

| 旧损失 | 加权梯度范数 | 各项范数之和中的占比 |
|---|---:|---:|
| Pixel | 2.256005 | 82.34% |
| Haar HF | 0.224962 | 8.21% |
| Edge | 0.023736 | 0.87% |
| SSIM | 0.211824 | 7.73% |
| MLS | 0.023484 | 0.86% |

旧图册坐标硬裁剪触发率为 **77.539%**，二次拟合受支持比例约 **72.5%**。这是特定探针，不是对所有训练位置的穷尽统计。梯度占比按各项范数求和归一，存在梯度方向抵消，不能当作总更新方向的严格贡献分解。

### 4.2 HybridWaveletNAFNet25D 的完整数据流

```text
原生 LR [B,1,7,64,64]
  ├─ Bicubic XY×4 ─────────────────────────── 基底 b [B,1,7,256,256]
  └─ LR 多尺度编码器
        64 通道 / 64×64
        128 通道 / 32×32
        192 通道 / 16×16
        NAF + XY 窗口注意力 + 跨 Z 注意力
                  │
Haar 状态 Xt [B,16,7,64,64] + 连续时间 t
                  │ 多尺度编码解码与跳连
                  ├─ LL：仅从 LR 条件预测 1 通道
                  ├─ HF：预测 15 通道干净端点
                  └─ HF：预测 15 通道 epsilon
                  │
              反白化 → 逆 Haar → 加基底
                  │
LR 特征 → PixelShuffle 64→128→256 → HR NAF 精修 → 最终 HR
```

NAFBlock 包含 SimpleGate 和简化通道注意力。窗口大小 8、注意力头数 4；跨层注意力在每个 XY 位置的 Z 序列上工作。编码器 blocks 为 `[2,2,4]`，精修宽度 16。

Haar 是 **4×4 正交块变换，16 个系数**：1 个常量 LL 加 15 个细节基，不应误写成普通单级 2×2 Haar 的总共 4 通道。训练目标为 `R=H(HR-b)`，再按 TRAIN 的 16 个通道均值和标准差白化。反白化和逆变换把损失送回实际归一化图像强度尺度。

LL 头只访问 LR 特征，不访问随机状态或时间。HR 精修虽然作用于全部像素，但其修正分支只依赖 LR、基底和确定性 LL 参考，避免通过随机 HF 再污染低频的确定性。插值可选 Bicubic/Lanczos，正式作业使用 Bicubic。

## 5. 训练损失与频带桥

### 5.1 全批量重建损失

```text
Lrec = Charbonnier
     + 0.3 (1-SSIM7)
     + 0.1 (1-MS-SSIM)
     + 0.01 FFT_log_amplitude
     + 0.05 FFT_complex_L1
     + 0.3 local_std_7x7_L1
     + 0.0 LPIPS                 # 正式配置当前关闭训练感知项
```

所有样本的起点重建均受结构和方差监督；SSIM 不再只取 1/8。精确 SSIM 计算使用 float64、切片分块及 checkpoint 降显存。局部标准差项直接约束对比度，FFT 项同时约束谱幅和复数差。训练 LPIPS 权重为 0 不影响每轮验证真实计算 LPIPS/FID。

exp1 只使用上述回归目标，`frequency_split=false, atlas_weight=0`，因此代码里保留 `sampling.steps=8` 不代表 exp1 真的执行了八次桥网络；其 restore 走直接端点分支。

### 5.2 exp2/exp3 的频带分裂桥

在白化 Haar 空间，训练中间状态为：

```text
Xt = (1-t) X0 + t R + sigma_max sqrt(t(1-t)) epsilon
X0 = 0，sigma_max = 0.08；epsilon 的 LL 通道恒为 0
```

时间主要连续均匀采样，另有 10% 起点/终点样本；噪声包络在两个端点严格为零。全批量另监督连续桥状态的端点重建，epsilon 损失权重 0.05。约 1/4 样本执行 2—4 步随机短轨迹，前缀不反传，最终读出监督权重 0.25，以缓解纯教师状态与部署状态的差异。

默认 PF-ODE 使用端点与 epsilon 估计形成高斯插值路径的条件流速度，而不是直接沿用旧的确定性 `(endpoint-X)/(1-t)`。二阶 Heun 配合 `time_min=0.001` 避免端点奇异；终端直接读出干净端点，无 t=1 除零。也支持温度 0—0.3 的低温 SDE。

这里实现的是**固定配对条件下的高斯桥边缘和匹配目标**，尚不能宣称求解了完整无配对最优薛定谔耦合。零初始状态的确定性 PF 推理本身也不产生多模态随机输出。合成数据上的稳定性不能保证真实 MRI 上增加步数一定单调提高 SSIM；正式 exp3 多步四指标尚未完成。

## 6. SC-JetAtlas 怎样与主网络耦合

### 6.1 建库与二阶几何

取 3×3 相邻 Haar 网格的 15 个 HF 系数，得到 **135 维**邻域向量，覆盖约 12×12 HR 像素。TRAIN PCA 压到 32 维；按病例划为 5 折，每个训练病例使用排除其所在折拟合的 PCA/图册。

每折配置 512 个中心、内在维数 8、256 邻居、低秩法向 rank=8。拟合带宽 h 与混合带宽 b 分开，`b=0.5h`；逐锚点通过 GCV 选择曲率正则。它是有限样本上的局部统计曲面，不是显式器官表面，也不是已证明覆盖全体 MRI 的解剖流形。

查询返回投影点、Jacobian、Hessian、薄 QR 切基 U、定向第二基本形式、解析平均曲率和软支撑距离。投影最多执行 2 步阻尼 Gauss–Newton；初始坐标采用光滑有理阻尼，而非旧硬裁剪。真实 MRI 有效支持率是否超过 95% 尚未形成完整终评证据，不能用合成曲面的 100% 支持率代替。

### 6.2 非对称损失、势能与曲率漂移

令 e 为预测与真值在 PCA 特征中的差，`eT=UUᵀe`。法向误差先减去 `0.5 B(eT,eT)` 的安全裁剪曲率补偿，再投到法空间。默认法向平方权重 1、切向权重 0.05；另有 XY 邻域法向一致性 0.1。几何选点目标为纹理 50%、强边缘 20%、弱结构 20%、背景 10%，不足时重新分配。

中间生成状态还接受到曲面和支撑边界的势能约束，权重 0.02；路由蒸馏权重 0.05。上述图册组合再乘全局 `atlas_weight=0.05`。势能作用于依赖模型输出的生成状态，能向主网络反传，不是只约束一个固定的教师张量。

exp3 的短轨迹训练启用低温 SDE 和 `0.5*g(t)^2*H` 曲率漂移，H 做安全限幅。默认正式验证为 ODE，因此不会凭空注入该随机漂移。几何先验旨在放松切向变化、限制法向伪影，但不保证自动恢复 LR 无法辨识的真实细节。

### 6.3 无 HR 推理路由与 EB 收缩

`SoftAtlasRouter` 输入为当前状态特征和 LR 条件。**当前落地实现的 LR 条件是原生 LR 的标量强度，`lr_dim=1`，不是完整学习型 LR 编码器特征。** 这是需要如实记录的设计差距。教师路由可以在 TRAIN 使用 HR；推理 API 不接受 HR。

在线时每折选择 top-3 图卡并软混合，5 折结果集成。经验贝叶斯修正仅收缩投影残差的法向分量，保留切向残差；当前噪声方差为配置/接口给定值，不能称为已从真实 MRI 在线校准的可靠噪声估计。默认在线几何从最终步启用。

按用户选定方案，**只训练一次 exp3，再冻结同一份 EMA/checkpoint 与图册/路由权重，分别关闭和开启 online_atlas**。比较程序验证权重 SHA256、相同病例/种子/步数，不用在线结果重新挑选另一份 checkpoint。这个方案已通过合成 PNG/四进程接口检查，真实 MRI 权重对照因 exp3 停止而尚未发生。

### 9.3 exp3 为什么停止、效率瓶颈在哪里

exp3 总训练 loss 从初期约976下降到 batch448 的15.116、batch480 的13.094、batch512 的5.689；这些值包含额外桥与几何项，不能直接与 exp1 约0.05的 loss 比大小。末端日志仍有限，没有 NaN/Inf 或 CUDA 崩溃证据；取消原因是用户要求优化效率。

实际训练峰值 allocated 约 **47.20 GiB/卡**。从准备结束到512个 batch 的粗估约 **35秒/batch**，整轮约13小时，60轮可能超过一个月，与7天 walltime 不匹配。它有持续推进，不是仅凭低吞吐就能认定死锁。

源码中的主要成本路径是：

- 正则按样本循环查询二阶图卡，投影还执行 QR、Gram 求逆和两次线性求解。
- 曲率短轨迹要重复调用在线查询；5折×top3图卡，query_chunk=256 产生较多小批量线性代数操作。
- 每卡48时短轨迹约12个样本，即使 stride4，`12×7×16×16=21,504` 个位置；乘5折及top3后约322,560次图卡查询/曲率调用，2—4步前缀可能调用1—3次。

已有 A800 单 worker 全流程探测约 exp1 4.37秒、exp2 6.36秒、exp3 42.13秒、exp4 41.59秒，含初始化等开销，不能当作精确纯训练计时，但方向与真实 exp3 慢一致。以上是源码与运行计时定位，尚未做逐算子 profiler，不能给每个 QR/路由模块分配未经测量的耗时百分比。

因此优化重点应是向量化跨样本查询、减少重复曲率几何查询、缓存可复用图卡量、将纯投影/仅曲率路径分开，以及增加更新级 checkpoint。不能只继续增大 batch，或认为显存未满就代表还应扩大图册查询量。本次报告任务没有擅自修改这些算法或重提作业。

## 10. 四指标评估的具体口径

1. **PSNR**：汇总全队列 SSE 和体素数形成 pooled MSE，再计算 `-10log10(MSE)`，data_range=1；不是病例 PSNR 的算术平均。
2. **SSIM**：7×7 均匀有效窗、样本协方差49/48，float64，XY切片等权；不是3D SSIM或高斯窗SSIM。
3. **LPIPS**：AlexNet、校准v0.1，lpips包0.1.4；灰度复制RGB，映射[-1,1]，按切片等权，使用离线校验过的真实预训练权重。
4. **FID**：torch-fidelity0.3.0，Inception pool3 2048维，`round(255*x)` 转uint8 RGB，提取器执行规定resize；float64聚合全局特征和/外积，N−1无偏协方差，仅计算一个队列级FID，分布式不平均各rank的FID。

推理复用原整病例重叠滑窗和 Hann 窗融合，融合后裁剪至[0,1]。每个完整 VAL 要覆盖595张切片并校验无漏病例/重复病例。v2 另记预测/真值局部方差能量的 pooled 比值和纹理区域SSIM；它们是诊断，不替代四项正式指标。

FID受样本量及切片相关性影响；这些都是二维 ImageNet 感知特征指标，不是3D解剖准确性或临床有效性证明。10例VAL也不足以替代多队列、多随机种子统计。
