# MRI 的 MLS 曲面几何

两条桥分别用同样的三维去噪表征配置学习训练集 HR。完整 4×4 XY Haar 系数送入编码器，以降低高分辨率卷积开销。编码器宽度为 24，空间池化特征为 64 维。最多收集 4096 个训练体块的特征并拟合 48 张二阶 MLS 局部图。内在维数由独立验证病例在 3、4、6、8 中选择。支持不足的图从候选集合移除。日志记录有效图数、验证特征覆盖率和曲面重建误差。

对每个训练配对，以 HR 特征定位一张图，在该配对的条件路径优化期间固定图 ID。用 MLS 曲面重建残差作为位置代价。用 MLS 解码 Jacobian 给出的切空间计算速度的法向分量，作为软运动代价。超出局部支持的查询使用最近有效锚点的受限坐标，远离曲面时降低切向约束的权重。

- GSBM 在原 LR 和 HR 之间优化高斯条件路径。几何位置代价在随机路径状态上计算，运动代价在均值样条段上计算。
- 动量桥仍在无损 Haar 残差坐标中保留位置、速度和解析参考转移。计算几何代价时，将位置还原为 MRI 强度，将速度还原为图像变化率，再用表征的中心差分估计特征速度。

两条桥在冻结图册后用优化路径生成匹配监督。推理只读取 LR。图册改变训练路径代价，参考噪声仍定义在原有桥坐标中。最终推理沿用末步无位置噪声和融合后裁剪。

GSBM 的 Slurm 作业在启动四卡进程前审计 MRI 配对与 PNG 头，并将病例索引写到本次作业目录。表征和桥训练的各 rank 读取同一索引并核对数据指纹。正式推理也使用该索引，按原固定清单校验和测试 15% 病例。

## GSBM 的 LR 条件图册与采样引导

`configs/mri_gsbm_mls_guided_x4.yaml` 将训练集配对的 LR 特征与 HR 图建立对应关系。训练、验证和测试都由实际 LR 选择候选图。路径状态在候选图之间按局部支持与距离软加权。每张 MLS 图的解码 Jacobian 提供局部切空间和诱导度量。超出支持时，约束平滑减弱。

端点固定的随机路径沿用 GSBM 的高斯变分族。路径目标包含环境控制动能、曲面势能和图册度量动能。几何权重随时间增加，使模糊的 LR 起点有进入 HR 曲面邻域的空间。训练在图像漂移匹配误差上加入特征空间度量误差。后者用编码器的中心差分计算漂移误差的特征变化，并在当前随机状态查询图册度量。

采样在内部时间步重新计算同一图册势能，通过冻结编码器求图像梯度，对非观测位置施加有界修正。末步使用模型漂移。对同一检查点，验证时用相同噪声种子分别运行有引导和无引导采样，记录两者的 MSE，按有引导 MSE 选权重。图册位于池化特征空间，随机参考过程仍定义在图像空间。

端点固定、先构造路径再匹配动力学参考 [BranchSBM §4](https://arxiv.org/html/2506.09007v2#S4)。将同一位置依赖度量用于路径动能与匹配误差参考 [MFM §3.2，式 6–7](https://arxiv.org/html/2405.14780v2#S3.SS2)。采样时的势能修正是本项目的近似引导。

当前配置每个体块最多选 3 张图，法向速度代价为切向的 3 倍。漂移特征误差权重为 0.05，采样从 (t>0.3) 开始引导，单步单体素修正上限为 0.002。路径和推理均使用原配对 MRI 输入、原 LR/HR 端点和固定测试病例清单。
