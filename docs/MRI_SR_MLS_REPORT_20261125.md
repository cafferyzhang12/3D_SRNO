# 配对 MRI 超分辨率算法架构、MLS 机制与阶段实验报告

**统计截止：2026-11-25 19:06（北京时间）**  
**代码版本：main / 60fc2eb；集群运行的算法源码为 78abda0，运行 YAML 已采用随后同步到 main 的 batch=544、workers=4 参数。**

## 1. 当前结论与证据边界

当前系统是以原生 LR 为条件、在 Haar 残差空间预测干净端点的四步确定性重建模型。训练同时监督起点预测和模型自身生成的中间状态；MLS 在训练期提供配对残差的局部二阶几何约束，推理不检索图册。

最新同预算消融已经完成对照组和 SSIM 组各 8 轮。SSIM 组在整病例 VAL 上得到 **32.562252 dB / 0.905722 SSIM**。相对冻结基准，PSNR 增加约 **0.009993 dB**，SSIM 增加 **0.00022465**；相对同预算对照组，SSIM 增加 **0.00010801**，PSNR 基本持平。收益方向正面，但幅度很小，尚不能称为显著突破，也没有多随机种子的统计证据。

MLS 分层选点与邻域约束组尚无完整轮次结果。当前证据不能证明这些新机制已经改善指标，也不能将整套架构相对历史基线的收益单独归因于 MLS。LPIPS、FID 和本轮固定 TEST 终评尚未完成。

## 3. 算法架构

```text
5 张原生 LR 切片 ── 条件编码器：96 → 160 → 256 通道 ─────────┐
       │             XY 下采样；深层 XY dilation=1,2,4       │
       └── 双线性 XY 放大得到基底 b                           │
                                                            ▼
归一化残差状态 Xt + 时间 t ──────────────── 干净端点预测网络 fθ
                                                            │
                                                   白化残差预测 R̂~
                                                            │
                                  反白化 → 逆 Haar → 加 b → HR 重建
                                                            │
训练：像素/Haar/边缘/SSIM/MLS 监督             推理：四步更新与整病例融合
```

### 3.1 Haar 残差与白化

令 H 表示正交 HaarXY 编解码中的编码操作：

- 基底：`b = BilinearXY(LR)`。
- 真值残差：`R = H(HR − b)`，每个 Haar 网格位置包含 16 个系数。
- 白化：`R~ = (R − μ) / (std + 1e−6)`，统计量仅由 TRAIN 拟合。
- 重建：`HR_hat = b + H⁻¹(R_hat~ × (std + 1e−6) + μ)`。

白化改变输入和预测参数的数值条件，不能自动创造缺失的高频信息。主重建损失仍在反白化后的物理强度尺度计算，避免不同频带被任意的白化权重主导。

### 3.2 条件分支与空间尺度

LR 编码器输出 96、160、256 通道的多尺度条件特征。对本任务 32×32 的原生 LR 输入，两个 XY stride=2 层对应 32→16→8 的平面网格；不能将最深层误写成 32×32。Z 保持 5 层。

256 通道深层使用平面内 dilation=1、2、4 的卷积残差模块，扩大 XY 上的上下文。新增空洞卷积不扩张 Z 方向，也不对 Z 下采样。网络通过多尺度 LR 条件、当前残差状态和时间共同预测端点。

### 3.3 当前四步动力学

当前配置 `sigma_0=0`、`sigma_bridge=0`，是确定性的条件迭代重建。它沿用了 Bridge Matching 的端点参数化，但当前实验不是带随机扩散的薛定谔桥，也不能宣称已经求得最优传输耦合。

从 `X0=0` 出发，在 `t=0,0.25,0.5,0.75` 预测干净端点。前三步采用：

`X_next = X + Δt × (fθ(X,t,LR) − X)/(1−t)`。

最后一步直接取端点预测，不在 t=1 计算除法。状态零点位于白化坐标系，解码时仍使用对应的均值与标准差。

训练对全批次起点预测监督；每卡抽取约 1/8 样本，通过真实四步推理前缀生成状态，前缀 stop-gradient，再监督最终读出和随机中间网格点。中间时刻取 0.25 或 0.5，最终读出时刻为 0.75。这样学习到的是部署实际访问的状态，而非只学习含真值信息的人工插值状态。

## 4. MLS 如何发挥作用

### 4.1 为什么超分需要几何先验

LR 给出了较可靠的大尺度强度和形状，却不足以唯一确定 HR 的细小纹理。只最小化平方误差时，对不确定细节取平均可能导致局部对比度变弱。MLS 的作用是利用 TRAIN 配对样本中重复出现的残差结构，约束网络的预测误差朝更符合局部数据几何的方向变化。

这里的“流形”是**局部图像系数向量的统计几何**，不是显式提取出的器官表面网格，也不是已证明覆盖所有 MRI 解剖结构的全局流形。

### 4.2 TRAIN 图册构建

已有配对银行采样得到 1,003,264 个位置，覆盖全部 3,919 个训练病例。每例采样 4 个块、累计 256 个位置，存储残差系数与配对基底系数。

图册采用 5 个病例级交叉拟合分组：对某训练病例施加损失时，使用排除了该病例所属折的样本拟合的图册。每折最多拟合 65,536 个位置，配置为 128 个中心、64 个邻居、4 维局部坐标。实际可用图册受支持度检查限制。

路由描述包含真值白化残差和配对基底系数。基底提供 LR 对应的观测上下文，残差提供当前训练样本应归属的几何区域。真值仅用于训练标签和正则选图，不作为推理输入。

局部拟合先估计 PCA 方向，再拟合带正则的二阶局部曲面。可以概念性写成：

`g(q) = m + 线性项(q) + 二次项(q,q)`。

代码中的带宽缩放、坐标范围约束和支持度权重共同限制不可靠的外推。前一轮图册预检中约 72.5% 图册具备受支持的二次拟合；这不等于 72.5% 病例获得了几何收益。

### 4.3 核心：以真值为锚点的曲面偏离损失

对位置 i，记反白化后的预测残差为 p_i，真值为 y_i，其局部坐标为 q_p、q_y。曲面缺陷定义为：

`d_i = (p_i − y_i) − [g_i(q_p) − g_i(q_y)]`。

局部几何损失为：

`L_MLS_local = mean_i [ w_i × ||d_i||² / 16 ]`。

它回答的问题是：**预测相对真值的变化，有多少能由本地曲面上的合理变化解释，还有多少是偏离曲面的变化？**

在线性近似下，曲面可解释的部分接近切向分量，剩余部分接近法向分量；二阶模型进一步包含局部弯曲。因此它是曲率相关的偏离约束，不是一个在所有位置恒定不变的法向投影矩阵。

真值锚定很关键：当 p_i=y_i 时，d_i 精确为零。即使有限样本拟合的曲面无法精确通过真值，也不会仅因图册拟合偏差而把正确预测拉走。

权重 w_i 包含 PCA 支持度和查询距离可信度，例如距离权重 `1/[1+(distance/radius)²]`。不可信局部图册受到减权。预测坐标通过投影和曲面解码保留梯度；图册参数、真值与路由选择不更新。坐标裁剪可限制外推，但也会限制裁剪区外的坐标导数。

### 4.4 MLS 与像素 MSE 的分工

MLS 允许沿数据曲面存在变化，因此单靠 MLS 无法保证选中正确的配对终点。像素 MSE 负责“到达这个病例的真实 HR”，MLS 负责“限制偏离训练数据局部结构的误差”。SSIM 再约束局部亮度、对比度和相关结构。

因此，MLS 是辅助几何先验，不能代替配对监督，也不能确保 LR 中不可辨识的细节被唯一恢复。

### 4.5 新增结构分层选点

原均匀采样容易让大面积简单区域占用大量正则预算。新版本根据 detached TRAIN HR 的局部 XY 方差、前景与梯度，将位置分为背景、弱结构、纹理、强边缘，目标比例为：

| 类别 | 采样目标 |
|---|---:|
| 背景 | 10% |
| 弱结构 | 20% |
| 纹理 | 50% |
| 强边缘 | 20% |

每块锚点预算仍为 256。某类不存在或不足时，配额会重新分配，所以实际比例不一定等于目标。该方法有意改变几何损失关注的区域分布，不应称为原均匀目标的无偏估计。

### 4.6 新增 XY 邻域几何约束

独立位置都接近某个曲面，并不保证相邻位置的误差协调。新项比较相邻 XY 位置的曲面缺陷：

`L_MLS_neighbor = mean_(i,j) [ min(w_i,w_j) × ||(d_i−d_j)/2||² / 16 ]`。

它约束的是**几何偏离的空间变化**，不是直接平滑 HR 图像；在正确重建处仍为零。使用共同物理 Haar 系数空间比较缺陷，避免直接比较不同图册的局部坐标。仅连接 XY 邻点，不连接 Z。

开启邻域项时，保持同一批锚点，额外查询其邻点，最多约三倍查询位置，并分块处理。其作用是减少相邻局部结构中不协调的几何误差，但它仍可能带来过度正则，需要单独消融。

### 4.7 推理期的作用方式

推理只运行网络和四步确定性采样，不加载 MLS 图册做在线硬投影。几何先验通过训练梯度写入网络参数，因而无需推理期 HR 路由，也避免在线 LR 图册误路由直接改变图像的风险。该设计不能等同于“推理结果被严格约束在图册曲面上”。

## 5. 当前损失和训练配置

对一个受监督预测，损失为：

`L_pred = [L_pixel + 0.1 L_HaarHF + 0.05 L_edge + 0.05(L_MLS_local + λ_neighbor L_MLS_neighbor)] / V_TRAIN + λ_SSIM(1−SSIM)`。

其中 `V_TRAIN≈0.000710569` 为固定 TRAIN 残差方差尺度；高频项将 LL 置零但保留 16 通道均值分母。边缘项比较 XY 误差有限差分，差分先除以 2。SSIM 在裁剪后的重建上计算；像素 MSE 保持未裁剪，以纠正越界预测。SSIM 是归一化物理损失之外的无量纲项，不能再按原始 MSE 的小数值随意混合。

总损失为起点损失，加上最终与随机中间状态损失的平均。SSIM 只在每卡约 1/8 样本上计算，采样前缀不反传。当前每卡完整批量 544，对应 68 个自采样样本；最后不足批量按实际大小处理。

| 参数 | 值 |
|---|---|
| 资源 | 4×A800 80 GiB，high qos，fundiff |
| 每卡/全局批量 | 544 / 2176 |
| 每卡数据加载进程 | 4 |
| 每轮样本预算 | 262,144 |
| 每轮更新 | 121，包含末尾不足批量 |
| 各消融轮数 | 8 |
| 初始学习率 | 2e−5 |
| 调度/稳定性 | 1 轮 warmup，cosine，梯度范数裁剪 1.0，EMA 0.999 |
| 起点 | 同一个冻结第 22 轮 EMA；优化器和调度器重新初始化 |

从每卡64增加到544后，更新数由1024降至121；因此本轮大批量实验不能与小批量版本按“相同轮数即相同优化预算”理解。四组内部使用相同设置，可以进行匹配比较。18:55 的运行快照显示每卡约64.1/80 GiB，计算利用率96%—99%；这只是时点观测，不是全程平均利用率或速度提升证明。

## 7. 选模与 LPIPS/FID

每个消融开始前重新评估冻结基准。只有 **VAL PSNR≥32.552259228086214 dB，且 SSIM 超过保留模型** 的候选才能替换best.pt；没有合格候选就保留基准。跨消融选择同样只使用VAL，之后冻结模型执行固定TEST。这个规则保证选出的VAL指标不退化，不保证未见TEST也不退化。

新增感知指标采用以下固定协议：

- LPIPS：AlexNet、校准v0.1，灰度复制RGB，强度映射至[-1,1]，原生XY分辨率，切片等权。
- FID：torch-fidelity的TF兼容Inception2048；灰度复制RGB，round(255×x)量化为uint8，特征提取器内部缩放至299×299。
- FID跨GPU合并float64特征计数、一阶和二阶矩后计算一次全队列距离，不平均病例FID或GPU FID。
- 预训练权重经过哈希与实际模型检查，正式评估使用验证后的离线缓存。
- MRI相邻切片相关，VAL仅595张而特征2048维，协方差秩不足；实现支持奇异协方差，但FID依旧受样本量影响。它是二维自然图像特征统计，不能视作三维解剖真实性的直接证明。

截止本报告，LPIPS/FID实际队列数值尚未产生，不填入估算值。

## 8. 工程状态和后续判断标准

本地及集群完整测试均264项通过；四卡显存探测和首次实际更新未出现OOM。预训练感知指标真实模型检查通过。当前训练作业5333866运行中，评估作业5333867等待训练成功结束，均为high qos。另一个项目的队列不属于本报告。

后续应依次检查：

1. 分层组相对SSIM组的增益，确认改变正则采样区域是否有效。
2. 邻域组相对分层组的增益，确认空间几何一致性项是否有效。
3. PSNR约束是否筛掉了SSIM较高但像素误差退化的候选。
4. 固定TEST上的PSNR、SSIM、LPIPS和FID是否方向一致；不再用TEST反向选择超参数。
5. 若提升仍很小，优先检查大批量导致更新预算减少、SSIM/MLS梯度贡献、图册支持度和坐标裁剪比例，而非直接扩大网络或推理步数。
